# Classes loaded reflectively by fully-qualified name — Class.forName, JNI
# lookups, etc. — and therefore MUST keep their original name through
# R8/minification.
#
# scripts/check-r8-kept-classes.sh asserts each is identity-mapped in the
# release build's mapping.txt. A rename (or removal) means a `-keep` rule in
# app/proguard-rules.pro is missing or broke — which ships a feature 100%
# broken in release builds while every *debug* test still passes (debug does
# not run R8).
#
# Add a class here whenever you pull in a dependency that resolves classes by
# string name. One fully-qualified class name per line; #-comments and blank
# lines are ignored.

# SSH Authentication API — OpenKeychain and other external key providers (#487).
# The binder matches the interface descriptor by name, and the error Parcelable
# is unmarshalled by class name; renaming either breaks provider-held keys in
# release builds while every debug test still passes.
org.openintents.ssh.authentication.ISshAuthenticationService
org.openintents.ssh.authentication.SshAuthenticationApiError

# sshlib's Ed25519 JCE provider reads its own package name at install time
# (Ed25519Provider.class.getPackage().getName()). Repackaged into R8's root
# package, getPackage() returns null and the SSH handshake dies with an NPE
# right after ECDH_REPLY (#513). Listed here rather than trusted to the keep
# rule alone: it is a name-dependency like the rest, and this is the only
# check that would notice the rule being dropped.
org.connectbot.sshlib.crypto.ed25519.Ed25519Provider
